# 🎮 Match-a-Shape Game

Match-a-Shape is an interactive shape–matching game built using a **React frontend** and a **Node.js + Express backend**.  
The project is designed to be simple, fast, responsive, and beginner-friendly, with a clean project structure for scalability.

---

## 🚀 Features

- 🎨 Modern and responsive UI  
- 🧠 Interactive shape–matching gameplay  
- 👤 Login & Signup functionality  
- 📊 Dashboard to show results or game progress  
- ⚡ Fast performance with React + Vite  
- 🔌 Backend REST API with Node.js & Express  
- 🛠 Modular folder structure for easy development  

---

## 📁 Project Structure

The project contains two main sections — backend API and frontend React app.

Wgame/
│
├── 📦 backend/ # Node.js + Express REST API
│ ├── controllers/ # API logic handlers
│ ├── routes/ # API endpoints
│ ├── middleware/ # Auth / validation middleware
│ ├── models/ # Database models (if any)
│ └── server.js # Entry point
│
└── 🎨 wgame/ # Frontend (React Application)
├── src/
│ ├── components/ # Reusable UI components
│ ├── pages/ # Page-level components
│ ├── assets/ # Images / icons
│ └── App.jsx # Main React entry point
└── package.json # Dependencies & scripts
